# ScentMuse 香氛探索产品方案

## 产品定位

面向有香氛兴趣但难以在线判断气味的用户，串联香调探索、风格导航、试香规格、收藏清单与试香意向。

## 本次定制

沿用 Vercel Commerce 的响应式商品卡、搜索、图库、规格与购物车；增加香氛品牌文案、8 件概念商品、4 个香调分类、3 类风格导航与本地数据提供器。购物车以浏览器 HTTP-only cookie 保存，清单预览不支付。

## 指标设计

发现漏斗：访问首页 → 风格导航 → 商品详情 → 选择试香 → 加入清单 → 预览清单。事件设计为 page_view、style_select、product_view、variant_select、cart_add、list_preview。

## 模拟研究计划

18 名概念目标用户访谈、2 轮原型迭代、60 条任务记录仅作为后续验证计划与简历草稿的模拟情境，不属于已完成的真实研究。

## 验收与边界

验证桌面与移动端布局、搜索空状态、筛选、详情与核心操作。现有实现是产品 Demo；没有真实用户增长、交易数据或外部品牌合作。开发与定制由 AI 工具辅助完成。
